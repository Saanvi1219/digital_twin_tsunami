# Digital Twin Intelligence System for Tsunami Hazard Prediction

## Study Area

Palu, Sulawesi, Indonesia

## Event

2018 Sulawesi Earthquake and Tsunami

## Features

- USGS Earthquake Integration
- Sentinel-2 NDWI Processing
- Digital Twin State Synchronization
- Okada Fault Model
- Shallow Water Equation Solver
- Dynamic Tsunami Intelligence Index (DTII)
- Hazard Classification
- Validation using RMSE, F1 Score and Pearson Correlation
- Interactive Dashboard
